## 🚀 Featured Projects

### 🔥 Real-Time Fire Detection & Extinguishing System
> Python · YOLOv5 · OpenCV · Streamlit · Twilio API

- Detects fire, smoke, and flame from live webcam feeds — **mAP 0.456, 60%+ precision**
- Streamlit dashboard with sprinkler simulation, manual override, and event analytics
- WhatsApp alerts via Twilio API for instant emergency notification

---

### 🧠 Harmful Brain Activity Classification (EEG)
> Python · Scikit-learn · PCA · Random Forest · Deep Learning

- Classified **6 types of harmful brain activity** from EEG data across **17,300 patients**
- Reduced features from 224 → 52 using PCA while maintaining **94%+ accuracy**
- Achieved **95% accuracy** with Random Forest, outperforming all baselines

---

### 🤖 RL-Based Anomaly Detection for Robotic Manipulation *(M.Tech Dissertation)*
> Python · TensorFlow · DQN · PPO · SAC · A2C · CASPER Dataset

- Compared 6 RL algorithms on the **CASPER industrial robotic arm dataset** (1.76M samples)
- **Dueling DQN** achieved best results; includes CNN-based visual encoders and hybrid BC+RL pipelines
- Advanced safety features: online anomaly monitoring, safe exploration zones via PCA, reward shaping

---

### 🏥 Blockchain-Based Healthcare Management System *(Research)*
> Python · Ethereum · Blockchain · ML · Role-Based Access Control

- Full-stack healthcare system with blockchain tamper detection and audit logging
- ML-based heart disease prediction with role-based access control (RBAC)
- Academic paper in progress (Springer/IEEE venue)

---

### ♿ Progressive Reading Aid for Visually Impaired
> Raspberry Pi · Deep Learning · Object Detection

- Real-time reading and navigation assistant deployed on Raspberry Pi
- Helps visually impaired users identify and interact with their environment
